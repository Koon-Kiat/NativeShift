# Changelog

All notable changes are recorded here. NativeShift follows Semantic Versioning.

## [Unreleased]

## [0.2.0] - 2026-08-02

- Added the native WinUI 3 conversion queue and C ABI GUI bridge.
- Added still-image conversion among PNG, JPEG, WebP, BMP, and TIFF.
- Added FFmpeg-based audio conversion and video remuxing/transcoding.
- Added runtime codec and hardware capability discovery with software fallback.
- Added resource-weighted scheduling, presets, settings migration, local
  structured logs, transactional outputs, and stable CLI JSON.
- Added Windows packaging, security analysis, SBOM, provenance, and release
  automation.
- Redesigned the desktop workflow around automatic file-type detection,
  persistent conversion history, responsive navigation, and centralized
  settings.
- Added whole-workspace drag and drop, image previews, visible conversion
  activity, and pin, archive, and delete actions for recent jobs.
- Made the self-contained portable EXE the default Windows distribution and
  reduced pull-request CI to the required high-signal checks.

## [0.1.0] - 2026-07-31

- Initial NativeShift release candidate.

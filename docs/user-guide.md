# User guide

Add files or a folder on the Convert page, optionally include subfolders, and
choose the output format. Search and type filters help with large queues.
NativeShift detects content rather than trusting the filename extension.

Choose a preset or expand detailed settings for resize, quality, codecs,
bitrate, frame rate, metadata policy, conflict behavior, and hardware
preference. Hardware `Auto` attempts only capabilities detected at runtime and
falls back to software with a visible warning.

Select an output folder, start the queue, and use Pause all, Resume all, Cancel,
Retry, Remove, or Clear completed. Each job exposes status, progress, provider,
codec, acceleration, warning, and failure details. Cancelling does not publish
a partial file.

Settings controls the default output, concurrency, theme, notifications,
logging, and preferences. Capabilities shows compiled encoders and usable
hardware devices. About links to licensing and privacy information. The logs
folder and privacy-safe diagnostic summary are available for troubleshooting.

Current limitations include animated/multi-page image output, document and
archive conversion, production signing, and hardware paths not present on the
current machine. Metadata support depends on the selected native path and a
warning is shown when a request cannot be honored.
